### #7 GNSS-denied (odometric random-walk drift) — HIGH value, LOW-MED cost (proposed)
- Replace the i.i.d. `sigma_loc` noise with a persistent random walk:
  `err += N(0, sigma_step)` per agent per step, observed position = true + err.
- **Injection point already exists and is reusable**: env.py `_observed_position`
  (line 519) corrupts the position feeding the local (and global-cluster)
  bearing angles. `noise_rngs` are seeded per (env_seed, agent) (env.py:159-161)
  → the walk is reproducible → paired design intact. `loc_error_sum` /
  `get_rmse_2d()` already record the drift for reporting.
- Decoupling preserved: the oracle Fisher accumulation uses TRUE geometry
  (env.py:438-456) → drift hits only the decision signal (and the global-cluster
  config record), exactly like sweep B.
- **Scaling caveat (reviewer's numbers are off by ~√N)**: a random walk's RMS
  error after N steps is σ_step·√N, not σ_step·N. "5-10 cells after 100 steps"
  would need σ_step ≈ 0.5-1.0. But real budgets are long (A6=1600, A3=3200,
  A2=4200 steps), so σ_step ∈ {0.05, 0.1} yields end-of-mission RMS drift of
  ~2-3 / 4-6.5 cells — a realistic severe-drift regime. Recommend framing by
  END-OF-MISSION drift, levels σ_step ∈ {0.05, 0.1} (plus optional 0.5 for a
  stress test).
- Rounding subtlety: `_observed_position` returns `int(round(...))`; sub-cell
  steps only bite once the accumulated walk crosses a cell boundary — realistic
  (odometry error grows until noticeable), but expect attenuated small-drift
  effects.
- Not modeled: a real GNSS failure would also shift the agent's belief frame
  (visit/coverage attribution). Here visit counts use TRUE position; the test
  corrupts only bearing origin. Acceptable first-order test; flag in prose.
- Cost: ~0.5-1 day (code ~30-60 min + smoke; wall ~2-3 h per sweep at 4 workers,
  resumable CSVs) + analysis/figure/§6.10 row. Reviewer estimated 1-2 days.
- Impact: a much harder robustness test of the locality thesis. If CU/RA's
  accuracy bonus survives accumulated odometric error → strong evidence; if it
  collapses → maps the boundary (like σ=1.0 in sweep B).

### #8 Agent dropout (mid-mission failure) — HIGH value, MED cost (proposed)

  perceiving; the rest continue; budget T (fixed steps) unchanged → survivors
  must cover more. Compare FB vs CU vs RA on A3/A6 (n=40).
- Variants: random dropout / planned (worst-agent) dropout / late-mission
  dropout. Each needs its own t_drop policy → 3 campaign runs.

- Protocol: same as established — paired seeds, Wilcoxon + Holm, coverage
